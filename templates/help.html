HELP & SUPPORT

Help Center

Quick answers for uploading documents, using RAG, understanding sources, and troubleshooting the local AI model.

How do I upload a document?
Open Upload, choose one or more PDF files, review the selected file list, then select Process documents. After indexing, the document appears in Documents and becomes searchable.
How does Ask AI work?
DocIntel converts document passages into embeddings, retrieves the most relevant passages with FAISS, and passes those passages to the local LLM. The answer is generated from that retrieved context.
Why are sources shown beside the answer?
Sources show the document and page passages retrieved for the current question. Select View relevant excerpt to read the complete retrieved passage in a focused window.
Why am I seeing “AI model unavailable”?
DocIntel uses Ollama for the local LLM. In Terminal run ollama list, make sure llama3.2 is installed, and start Ollama with ollama serve. Then return to Ask AI and ask again.
What if the answer is not in my documents?
DocIntel is instructed not to invent facts. When relevant evidence cannot be found, it should clearly tell you that the uploaded documents do not contain enough information.
Where do Contact Us messages go?
Messages are saved locally in the SQLite database in the contact_messages table. The first account created is marked as the local administrator and can open Settings → Contact Inbox to read them.
